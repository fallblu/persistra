# Release evidence

Persistra uses two standard supply-chain records for release distributions:

- a CycloneDX 1.6 JSON software bill of materials (SBOM) generated from an isolated environment
  containing the exact locked runtime dependencies and built wheel; and
- an in-toto statement with a SLSA v1 build-provenance predicate generated by GitHub Actions.

The same GitHub workflow also wraps the CycloneDX document in an in-toto SBOM attestation. Both
signed statements identify the wheel and source distribution by SHA-256 digest. GitHub issues each
workflow run a short-lived Sigstore certificate; no long-lived signing secret is stored in the
repository.

## Human-controlled generation

The `Release evidence` workflow never creates a tag, GitHub release, or package publication. Start
it only after the complete release gate passes on a version-matched `release/X.Y.Z` or
`hotfix/X.Y.Z` branch, or on an annotated `vX.Y.Z` tag:

```bash
gh workflow run release-evidence.yml --ref release/X.Y.Z
```

The workflow rejects `develop`, `main`, mismatched versions, lightweight tags, and other refs. It
checks out the selected ref without credentials, builds the wheel and source distribution from
that exact commit, creates the SBOM from an isolated runtime-only environment, and signs both
attestations with job-scoped `id-token`, `attestations`, and `artifact-metadata` permissions. It
does not receive `contents: write`, `packages: write`, or a publishing token.

Run `make release-evidence` locally to inspect unsigned distributions, the SBOM, checksums, locked
runtime requirements, and build metadata. Local generation cannot create a trusted GitHub
attestation.

## Verification

Download the workflow artifact without renaming its contents. From its root, verify every retained
file digest:

```bash
sha256sum --check release-evidence/SHA256SUMS
```

Verify the SLSA provenance for both distributions against this repository and signer workflow:

```bash
gh attestation verify dist/persistra-X.Y.Z-py3-none-any.whl \
  --repo fallblu/persistra \
  --signer-workflow fallblu/persistra/.github/workflows/release-evidence.yml
gh attestation verify dist/persistra-X.Y.Z.tar.gz \
  --repo fallblu/persistra \
  --signer-workflow fallblu/persistra/.github/workflows/release-evidence.yml
```

Verify the SBOM claim by adding `--predicate-type https://cyclonedx.org/bom` to either command.
Use `--source-ref` and `--source-digest` when enforcing one expected release ref and commit.
Portable Sigstore bundles are included for offline retention, though normal verification fetches
the repository attestations from GitHub.

## Retention

The workflow artifact is retained for 90 days. Before it expires, the human release operator
downloads it and attaches the wheel, source distribution, CycloneDX SBOM, `SHA256SUMS`, and both
Sigstore bundles to the corresponding GitHub release or an approved durable archive. Keep the
files together and preserve their names. Repository attestations remain discoverable through the
GitHub attestations API, but they do not replace retention of the published distributions and
standalone evidence.
